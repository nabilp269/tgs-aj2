Deskripsi Proyek

Monitoring Sensor IoT dibuat untuk membaca dan menampilkan data dari beberapa sensor lingkungan secara terpusat. Sistem ini membantu pengguna memantau kondisi ruangan, mendeteksi potensi bahaya, serta menerima informasi sensor melalui web maupun aplikasi.

Fitur Utama

  • Monitoring suhu dan kelembapan secara real-time
  • Deteksi api sebagai peringatan awal kondisi darurat
  • Pemantauan kadar gas dan status keamanan lingkungan
  • Dashboard web dan aplikasi mobile Flutter yang responsif
  • Komunikasi data melalui REST API dan Bluetooth
