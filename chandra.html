Deskripsi Proyek

Sahabat Chandra merupakan sistem web remitansi dan layanan keuangan modern yang menghubungkan kebutuhan nasabah pengirim uang (mata uang Hong Kong Dollar / HKD) ke berbagai rekening bank di Indonesia. Aplikasi ini dibangun dengan arsitektur modern berbasis Laravel Breeze, Inertia.js, dan React.js untuk antarmuka Single Page Application (SPA) yang cepat dan mulus. Dilengkapi integrasi Laravel Reverb untuk WebSocket real-time, database handal PostgreSQL, styling responsif dengan Tailwind CSS, serta version control terkelola di GitHub.

Fitur Utama Sistem:

  • Autentikasi & Role (Laravel Breeze): Pemisahan peran yang aman antara Admin operasional dan Pengguna (Nasabah).
  • Real-time Updates (Laravel Reverb): Pelacakan dan notifikasi status pengiriman uang secara langsung tanpa refresh halaman.
  • Seamless User Experience (Inertia + React): Navigasi antarmuka cepat, interaktif, dan reaktif di seluruh modul dasbor.
  • Penyimpanan Data Terstruktur (PostgreSQL): Pengelolaan data transaksi nominal HKD, riwayat pengiriman, dan akun nasabah secara reliabel.
  • Peta Cabang Berbasis Koordinat: Penentuan lokasi cabang fisik terdekat dan jam operasional untuk kemudahan nasabah.
